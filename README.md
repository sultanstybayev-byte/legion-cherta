# Карта мира, план базы и сообщество легиона

Сайт для мира на сборке Ascension of Ages (Minecraft 1.21.1).

| Страница | Что там |
|---|---|
| **Карта** `index.html` | 2D-карта в координатах игры, сетка чанков и регионов, метки, поиск, переход по координатам, линейка, пересчёт в Незер |
| **План** `plan.html` | 3D-платформа из чанков, база «Лотос Легиона» с твоими правками, задачи на чанках |
| **Задачи** `tasks.html` | списки задач: «Нужно сделать → В работе → Готово», с исполнителями |
| **Форум** `forum.html` | разделы «Предложения», «Заявления», «Общее», «Новости» |
| **Горячий чат** `chat.html` | короткие сообщения о том, что сейчас делается на базе |
| **Участники** `users.html` | роли и блокировки (видят модераторы, меняет только владелец) |

## Шаг 1. Сайт на GitHub Pages

1. На github.com нажми **New repository**, назови, например, `legion-map`, сделай **Public** и нажми **Create repository**.
2. **Add file → Upload files**. Перетащи **всё содержимое** этой папки и нажми **Commit changes**.
3. **Settings → Pages** → **Deploy from a branch** → ветка **main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ_ЛОГИН.github.io/legion-map/`.

Если сайт у тебя уже выложен, просто загрузи новые файлы с заменой.

> **Перед переходом на сервер сохрани свои данные.** На старой версии сайта: **Настройки → Скачать world.json**. Потом этот файл переносится на сервер (шаг 5).

## Шаг 2. Бот в Telegram (2 минуты)

1. Открой в Telegram **@BotFather** и отправь `/newbot`. Придумай имя, например «Легион Черта», и ник, который заканчивается на `bot`, например `LegionChertaBot`.
2. BotFather пришлёт **токен** вида `123456789:AA…`. Сохрани его, это секрет.
3. Отправь BotFather `/setdomain`, выбери своего бота и пришли адрес сайта **без пути**: `ТВОЙ_ЛОГИН.github.io`.
4. Узнай свой Telegram ID: напиши боту **@userinfobot**, он ответит числом **Id**. По нему сервер узнает владельца.

## Шаг 3. Сервер на Cloudflare (бесплатно, около 10 минут)

1. Зарегистрируйся на **dash.cloudflare.com**. Банковская карта не нужна.
2. **База данных.** Слева **Storage & Databases → D1 SQL Database → Create**. Имя: `legion-map` → **Create**. Таблицы сервер создаст сам.
3. **Сервер.** Слева **Workers & Pages → Create → Create Worker** (шаблон «Hello World»). Имя: `legion-api` → **Deploy**.
4. Нажми **Edit code**. Удали весь код в редакторе, вставь содержимое файла `server/worker.js` из этой папки и нажми **Deploy**.
5. Открой воркер → **Settings → Bindings → Add → D1 database**. **Variable name**: `DB`, база: `legion-map` → **Add/Deploy**.
6. **Settings → Variables and Secrets → Add**, три штуки:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | **Secret** | токен от BotFather |
| `OWNER_ID` | Text | твой Telegram ID (число) |
| `ALLOWED_ORIGIN` | Text | `https://ТВОЙ_ЛОГИН.github.io` (без `/legion-map` и без слеша в конце) |

   Нажми **Deploy**.
7. Наверху страницы воркера есть адрес вида `https://legion-api.ИМЯ.workers.dev`. Открой в браузере `…workers.dev/api/me`. Если видишь `{"user":null,…}`, сервер работает.

## Шаг 4. Связать сайт с сервером

В репозитории открой `js/config.js`, нажми карандаш (**Edit**) и впиши:

```js
window.SITE_CONFIG = {
  api: 'https://legion-api.ИМЯ.workers.dev',
  bot: 'LegionChertaBot'
};
```

Нажми **Commit changes** и подожди минуту.

## Шаг 5. Первый вход и перенос данных

1. Открой сайт → **Войти через Telegram** → подтверди вход. Рядом с именем должно быть «Владелец».
2. **Настройки → Загрузить world.json на сервер…** → выбери файл из шага 1. Метки, план, база и картинки карты переедут на сервер.
3. Там же: название мира и сид.
4. Дай друзьям ссылку на сайт. Когда они войдут и напишут заявление, выдай роли на странице **Участники**.

Токен GitHub, который ты вводил раньше, в режиме с сервером больше не нужен. Его можно удалить на GitHub: Settings → Developer settings → Fine-grained tokens.

**Резервная копия:** Настройки → **Скачать резервную копию**. В ней всё: метки, план, форум, чат, задачи, участники. Делай её иногда.

## Картинка мира

Сида мало: сборка с модами меняет рельеф и биомы, а карты по сиду (Chunkbase) знают только ванильный мир. Картинку делают из файлов сохранения:

1. Скачай бесплатную программу **uNmINeD** (unmined.net).
2. Открой в ней папку мира: обычно `…/instances/Ascension of Ages/saves/ИМЯ_МИРА`, а для сервера — папку `world`.
3. Экспортируй карту в PNG. Блоки из модов могут быть серыми, это нормально.
4. Положи файл в папку `map/` репозитория, например `map/overworld.png`.
5. На карте (нужна роль модератора): **Картинка карты** → впиши `map/overworld.png` → **Применить**.
6. Если картинка стоит не на месте, нажми **Привязать по двум точкам**: кликни по месту с известными координатами и впиши его X и Z, потом то же для второй точки.

Держи картинку не больше 8000 пикселей по стороне. Для большого мира экспортируй её с уменьшением (2–4 блока в пикселе).

## Правки базы из страницы «Лотос Легиона»

Там нажми **Скопировать для планировщика**, потом на сайте **План → Вставить мои правки базы…**.

## Управление в 3D (План)

Тяни мышью — осмотреться. **W A S D** — лететь, **Space / C** — вверх и вниз, **Shift** — быстрее, колесо — вперёд и назад. Клик — выбрать чанк, **Shift + клик** — добавить ещё, **Esc** — снять выбор. «Вид сверху» удобен для разметки.

## Лимиты бесплатного Cloudflare

100 000 запросов в день. Открытый горячий чат проверяет новые сообщения раз в 4 секунды, это около 900 запросов в час на одну вкладку. Для легиона из нескольких десятков человек этого хватает с запасом.

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| Кнопка Telegram не появляется | Проверь `/setdomain` у BotFather: адрес без `https://` и без пути. |
| «Telegram не подтвердил вход» | Проверь, что `BOT_TOKEN` вставлен целиком и это токен того же бота, что указан в `js/config.js`. |
| «Нет связи с сервером» | Проверь адрес `api` в `js/config.js` и `ALLOWED_ORIGIN` в воркере: там должен быть ровно адрес сайта, например `https://login.github.io`. |
| Ты вошёл, но не «Владелец» | Сверь `OWNER_ID` с Id от @userinfobot. |
| «не привязана база данных D1» | Шаг 3.5: привязка должна называться именно `DB`. |

|---|---|
| `js/config.js` | адрес сервера и имя бота — **единственное, что нужно поменять** |
| `server/worker.js` | код сервера для Cloudflare (на GitHub он не обязателен, но и не мешает: секретов в нём нет) |
| `js/common.js` | вход, роли, сохранение |
| `js/map.js`, `js/plan.js`, `js/forum.js`, `js/chat.js`, `js/tasks.js`, `js/users.js` | страницы |
| `js/lotus.js` | модель здания |
| `data/world.json` | данные для простого режима без сервера |
| `map/` | картинки карты |
